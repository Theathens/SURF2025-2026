# Round2 Public Blind Dataset

This package contains three virtual-company ESG disclosures and virtual-AOI remote-sensing proxy features for a blind consistency-detection exercise. Use the final disclosed values and report text as the inspection target.

Files:

- `round2_public_blind_esg_reports_2025.md`: complete 2025 ESG reports for the three companies.
- `round2_public_blind_historical_esg_texts_2018_2024.md`: historical text context.
- `round2_public_blind_annual_esg_metrics_2018_2025.csv`: annual energy, emissions, activity, governance, water, and waste disclosures.
- `round2_public_blind_green_power_carbon_credit_2018_2025.csv`: renewable-electricity and carbon-credit disclosures.
- `round2_public_blind_virtual_aoi_claims.csv`: nine facility-level public ESG claims.
- `round2_public_blind_virtual_aoi_remote_sensing_features_2018_2025.csv`: virtual AOI and simulated remote-sensing proxy features. Coordinates are simulated and are for internal dataset linkage rather than real-world imagery download.
- `round2_group3_detection_submission_template.csv`: suggested return format.

For each finding, identify the inspected statement or metric, cite the evidence file and field/section, describe the consistency concern, and provide a confidence value.
