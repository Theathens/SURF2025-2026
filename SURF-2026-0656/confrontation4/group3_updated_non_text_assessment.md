# Group3 更新程序非文本通道评估

评估对象：`data(1).zip`  
评估范围：结构化通道与卫星通道，文本通道完全排除

## 一、总体判断

新版程序在数据处理和误报控制方面有实质进步，但正式侦测结果没有整体改善。

- 工程进步：生成16条真实GEE观测、16幅非空且哈希唯一的影像，覆盖4个真实厂区和
  2022—2025年。
- 精度进步：非改动公司年份误报候选由7个降至0个。
- 召回下降：10个真值公司年份中，只对LONGi 2023和2024形成正式发现。
- 定位仍未成功：LONGi真实修改字段为Scope 1、Scope 2和Scope 1+2排放，新发现检测的是
  电耗和可再生电力占比。
- 正式卫星通道仍未落地：`satellite_detection_submission.csv`为0行。

因此，本次更新属于**底层能力进步、最终检测输出尚未同步进步**。程序从较多宽泛风险提示
转向极少量高阈值提示，误报下降，但漏检明显增加。

## 三、相比上一版的进步

### 1. 误报控制改善

上一版存在7个非改动年份误报候选；更新版没有在非改动年份形成正式发现。检测阈值更加
保守，输出精度有所提高。

### 2. 真实GEE处理已经落地

更新版已经生成并保存：

- AOI边界；
- 年度影像日期；
- 建成区面积；
- 屋顶光伏面积及容量代理；
- 夜间灯光；
- NDVI；
- 地表温度和热指数；
- Sentinel-2、Dynamic World、VIIRS和MODIS来源。

16幅影像均非空且文件哈希不同，说明不是简单复制同一张图片。

### 3. LONGi部分年份得到定位

更新版在LONGi 2023和2024发现了年度异常。虽然未命中真实修改字段，但相比上一版完全
没有定位LONGi目标年份，属于公司年份层面的进步。

## 四、仍未改善的问题

### 1. LONGi没有命中真实修改字段

Group2实际修改：

- `scope1_emission_tco2e`
- `scope2_market_based_tco2e`
- `scope1_2_emission_tco2e`

更新版提交：

- 2023年`electricity_mwh`同比异常；
- 2023年`renewable_electricity_ratio_pct`下降异常；
- 2024年`renewable_electricity_ratio_pct`上升异常。

这些结果说明程序找到了同一公司年份附近的异常，但没有识别“排放轨迹平滑”机制。

### 2. 其他真值事件没有形成发现

Haier、Sungrow、Anchor、Nova和Orion的目标事件没有进入正式结构化或卫星提交结果。
检测器可能因阈值过严而失去召回能力。

### 3. 正式证据链仍不完整

3条结构化发现的以下字段全部缺失：

- `table_name`
- `field_name`
- `evidence_file`
- `evidence_location`

同时，2023年电耗数值12,267,985被标记为`%`，正确量纲应为电量单位。`raw_findings.csv`
中的`reported_value`和`recalculated_value`实际对应本年值与上年值，并非披露值与独立复算值。

### 4. GEE成果没有转化为正式卫星发现

真实GEE表已生成完整代理变量，但`satellite_detection_submission.csv`为空。`facility_panel.csv`
中的真实厂区“原值”和“复算值”三组字段在16行中全部相等，说明合并后没有保留独立披露
基准。

尤其是Sungrow 2025，程序已经取得屋顶光伏面积和容量代理，却没有进一步与公司披露的
光伏发电量建立物理一致性比较。

## 五、改进建议

1. 对Scope 1、Scope 2和Scope 1+2建立多年度平滑度、与产量或电耗脱钩及残差异常检测。
2. 将公司披露的光伏发电量与GEE屋顶面积、估算容量和合理利用小时建立独立比较。
3. 将有效遥感比较结果写入`satellite_detection_submission.csv`。
4. 补全`table_name`、`field_name`、`evidence_file`和`evidence_location`。
5. 保留当前低误报策略，但增加机制级规则，避免Haier、Sungrow和虚拟公司事件全部漏检。

## 六、结论

新版程序值得保留的成果是：真实GEE影像获取、遥感变量生成、无重复面板结构和较好的误报
控制。下一步重点不是继续收紧阈值，而是把这些底层结果转化为可核查的正式检测发现。
