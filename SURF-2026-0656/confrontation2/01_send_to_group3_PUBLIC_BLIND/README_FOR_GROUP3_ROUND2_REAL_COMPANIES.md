# Round2 Public Blind Dataset: Real Companies

This package contains final disclosed claims, structured ESG data, and facility point seeds/time windows for three real companies. Use the materials to identify potentially inconsistent ESG disclosures and explain the evidence used.

- `round2_public_blind_real_company_claims.csv`: claim-level cases and disclosed values.
- `round2_public_blind_revised_disclosure_text.md`: fuller disclosure text for the claim cases.
- `round2_public_blind_real_company_metric_panel.csv`: annual disclosed energy and emissions metrics.
- `round2_public_blind_real_company_green_power_carbon_credit.csv`: green-power and carbon-credit disclosures.
- `round2_public_blind_facility_coordinates_time_windows.csv`: facility coordinates and annual time windows. These are point seeds only; no verified AOI polygon or measured satellite proxy values are provided.
- `round2_group3_detection_submission_template.csv`: suggested return format.

When reporting a finding, cite the file and specific field or text section, then explain the suspected inconsistency and confidence level.
