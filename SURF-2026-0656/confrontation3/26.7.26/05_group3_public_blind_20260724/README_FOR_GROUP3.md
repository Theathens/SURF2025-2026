# SURF Round3 Group3 public blind package

Package ID: `ROUND3_GROUP1_TO_GROUP3_PUBLIC_BLIND_20260724`

## Scope

This package contains six company cases in two separately classified cohorts. Each
cohort includes complete ESG report text, annual ESG indicators, green-power and
carbon information, and facility/AOI information.

## Directory policy

- `real_companies/`: public-company reference cases.
- `virtual_companies/`: controlled-company cases.
- `return_templates/`: blank templates for Group3 findings.

Do not merge the two cohorts without retaining a cohort indicator. Blank fields
mean unavailable or undisclosed information and must not be converted to zero.

## Detection submissions

Each finding should identify the company, year or facility, table or report
location, field or statement, calculation or evidence, confidence and conclusion.
Satellite findings should state the AOI, image date, unit and spatial boundary.

This package contains no scoring key, internal findings or prior-value ledger.
